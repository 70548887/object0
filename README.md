# 云仓 Yuncang

**简体中文** | [English](README.en.md)

**一个桌面管理端，统一管理多个云存储账号和空间。**

云仓将七牛云 Kodo、Cloudflare R2、Amazon S3 等存储连接放在同一个窗口中：选择账号、切换空间或存储桶，浏览文件、上传下载、查看任务目标和生成分享链接。

基于 [sayedhfatimi/object0](https://github.com/sayedhfatimi/object0) 开发，保留上游 MIT 许可证与版权声明。

[下载预览版](https://github.com/70548887/object0/releases/tag/v1.7.0-preview.2) · [发行说明](docs/RELEASE_v1.7.0-preview.2.md) · [MIT 许可证](LICENSE)

> **预览版说明**：七牛功能已接入多项应用链路，但不等于完整 Kodo 控制台或所有公有云／私有云环境已验收。重要数据请先备份，并使用独立测试空间验证权限与操作行为。
>
> **本地凭据风险**：本版默认将 AK/SK **明文保存在本机** `accounts.local.json` 中，不要求云仓密码或恢复密钥。能读取该文件的程序也能读取凭据。请勿共享账号文件、上传到代码仓库或放入发布包。

## 本次修复

- 排队复制／移动绑定源、目标账号的版本和服务商；归档下载与队列删除增加同类保护，账号修改后旧任务会被拒绝，不会悄悄转向新连接。
- 进入／返回目录时立即清除旧文件行、选择和操作目标，避免在新目录加载期间误操作旧文件。
- 文件浏览器统一负责自动加载，目录、面包屑、后退、标签和页大小变更不再触发重复列表请求；手动刷新及分页仍保留。

## 支持哪些存储服务

添加账号时先选择服务商，不固定进入七牛；每个账号独立管理自己的空间列表和连接配置。

| 服务商 | 连接方式与空间管理 |
|---|---|
| **七牛云 Kodo** | 公有云原生 API，按账号发现空间并按空间解析区域；私有云／受限身份提供显式配置路径，见下方限制。 |
| **Cloudflare R2** | S3 兼容接口，多账号、多桶；区域通常为 `auto`，桶级凭据可指定默认桶。 |
| **Amazon S3** | AWS S3 接口，使用相应区域与访问凭据。 |
| **DigitalOcean Spaces** | 使用空间所在区域的 S3 兼容 Endpoint。 |
| **MinIO** | 连接自己的 MinIO S3 服务。 |
| **Google Cloud Storage** | 使用已启用的 **S3/XML 互操作接口及 HMAC 凭据**，不是 Google OAuth 或原生 JSON API。 |
| **Backblaze B2** | 使用对应区域的 S3 兼容接口。 |
| **自定义 S3 兼容存储** | 手动填写 Endpoint、Region 和凭据；可用功能取决于服务实现。 |

“支持连接类型”不代表所有服务商提供相同功能。空间是否可列出、对象是否可读写、能否签发链接，均受实际凭据、区域和服务端策略约束。

## 产品功能

### 多账号、多空间统一管理

- 左侧切换存储账号，查看该账号的空间／存储桶列表。
- 同时打开多个空间标签，按目录浏览文件；搜索、详情、排序与分页使用现有文件管理界面。
- 七牛空间显示区域和权限提示；空间原生名称与 S3 标识分开处理，不把显示名当作接口标识。

### 上传、下载与任务追踪

- 使用上传按钮选择文件；也可从电脑将**多个文件直接拖入桶内容区或下方空白处**，上传到当前目录。
- 拖拽时显示目标桶和目录；切换账号、桶或目录后，旧手势不会偷偷改传到新位置。
- 文件夹请使用“上传文件夹”入口；能否执行由对应服务商当前支持范围决定，不将目录拖入伪装为普通文件上传。
- 任务列表显示创建时记录的**账号名称、服务商、桶和完整对象路径**，支持复制位置信息；以后切换或重命名账号不会改写该快照。
- 旧任务未保存过的账号信息明确显示“未记录”，不根据当前页面猜测。
- S3 连接保留现有复制、移动、删除及同步能力；七牛尚未完成的相关功能明确禁用，见下方能力边界。

### 文件分享与用量

- 单文件外链、复制链接和二维码；S3 签名链接最长 7 天，仍受服务端和凭据有效期限制。
- 七牛可选择当前空间的源站、CDN 或测试域名，默认选第一个可用项。HTTP 会明确提示明文传输，不自动将 HTTPS 降级。
- 已确认公开且未保护的七牛资源使用公开直链，**客户端不能强制其按所选时间过期**；私有／受保护资源使用限时签名。七牛原生签名链接的 30 天上限是应用策略，不是可访问性保证。
- 底栏显示用量、对象数、数据来源和刷新状态；官方统计不完整时显示部分结果或有界扫描来源，读取失败不冒充零用量。
- 深浅主题、中英即时切换、键盘操作及窄窗口布局。

## 七牛云 Kodo 当前能力

本预览版保留云仓的 Tauri／Rust 架构，参考 [七牛 Kodo Browser](https://github.com/qiniu/kodo-browser) 的业务和协议实现，**不是将其 Electron 客户端直接嵌入云仓**。

已接入：

- 公有云普通账号 **AK/SK 一键连接**，发现空间、区域和基础文件列表。
- 原生文件上传；超过 5 MiB 的公有云原生永久凭据上传使用持久分片任务，可暂停并手动恢复。
- 通过配置或已发现的下载域名下载文件，公有原生下载接入 Range 持久恢复。
- 单文件外链、域名选择，以及公开／私有链接区别。
- 公有目录只读分享创建、提取码登录、授权范围内浏览和单文件下载。
- 六类官方用量／对象数统计与有明确来源的有界扫描回退。
- 受限账号和 Session Token 的显式“限定空间／S3 绑定”读取路径；空间名称、S3 ID、区域和 Endpoint 必须明确配置。

仍有限制：

- 私有云及受限身份路径主要经过本地模拟契约验证，**未完成目标私有部署实机验收**；绑定模式、私有云和临时凭据上传尚未开放。
- 私有分享创建、私有／S3 持久传输恢复、七牛跨空间／跨云复制移动与同步、递归目录管理、限速、完整预览和受控文本编辑尚未完成。
- 删除型镜像同步保持关闭。不要把禁用按钮算作已经实现，更不要用本预览版对生产数据作镜像清理。
- 实际下载和分享仍受域名绑定、证书、测试域名期限、文件类型及服务端访问策略影响；生成了链接不代表外部可访问性已经验证。

详见：[七牛上传](docs/QINIU_RESUMABLE_UPLOADS.md) · [断点下载](docs/QINIU_RANGE_DOWNLOADS.md) · [目录分享](docs/QINIU_DIRECTORY_SHARING.md) · [文件外链](docs/QINIU_SHARE_LINK_FIXES.md) · [用量统计](docs/QINIU_USAGE.md) · [任务目标记录](docs/JOB_LOCATION_SNAPSHOTS.md)。

### 快速开始

1. 启动程序，直接进入本地账号界面。旧加密库可使用原云仓密码一次性导入，也可跳过；原文件保留，不强制要求恢复密钥。
2. 点击“添加账号”，先选择七牛、R2、S3 等服务商，再填写对应连接信息。普通七牛公有云只填 AK/SK 后点“连接”；私有云和受限身份使用七牛高级配置。
3. 在左侧选择账号和空间／桶，进入目录后上传、下载或拖入电脑文件。
4. 从任务面板查看状态、失败原因和真实目标账号／空间。
5. 在“设置 → 语言”切换中文或 English；README 顶部也提供中英文切换。

语言切换不会翻译账号名、桶名、文件名、对象键、URL 或密钥。

## 数据与升级

- 本地账号保存在 Windows 当前用户的 `%USERPROFILE%\.config\object0\accounts.local.json`，默认为明文；旧 `vault.enc` 仅作为保留和可选导入来源。
- “便携”表示应用无需安装，不表示账号跟随 ZIP 或 U 盘移动。发布包不包含预置账号、凭据、密码库或用户任务。
- 安装版与便携版共享程序标识及本地配置；请一次只运行一个版本，升级前等待任务结束并备份配置。
- 新版能读缺少目标快照的旧任务；旧版本不保证能读新增字段的原生断点记录，不要用删库或删任务文件的方式降级恢复。
- 上游自动更新默认停用，请从本仓库手动下载版本。

## 开发与验证

技术栈：**Tauri 2 · Rust · React · TypeScript · Tailwind CSS**。使用 **Bun**，不使用 npm、pnpm 或 yarn。

```sh
bun install --frozen-lockfile
bun run test:frontend
bun run build
cargo test --manifest-path src-tauri/Cargo.toml --release --lib --locked
bun run tauri dev
```

Windows 构建需按 `packaging/windows-runtime.json` 准备固定 WebView2 运行时。最近功能阶段本地验证为 Rust **433 项通过、1 项忽略**，前端 **284 项／27 组隔离回归通过**；这些结果来自本地测试和模拟契约，不代表所有真实云环境或安装流程均已验收。以[本版本发行说明](docs/RELEASE_v1.7.0-preview.2.md)记录的验证范围为准。
