# 七牛原生下载：Range 恢复与本地文件保护

日期：2026-10-31，分支 `feature/qiniu-kodo`。本轮把 Range 下载接入真实任务调度代码、加密记录和既有暂停/恢复界面；验证使用本地模拟服务与临时文件，不代表真实七牛、真实桌面进程重启或所有私有部署已经验收。

## 已接通的用户路径

- 公有云、永久凭据、非显式 S3 绑定的七牛文件下载进入持久队列，包括普通文件下载和分享弹窗的“使用所选域名下载”。
- 任务显示为下载类型，并由后端授予 `resumable`；并非所有供应商或所有下载都自动获得恢复能力。
- 复用 `jobs:pause`、`jobs:resume`、`jobs:retry`、`jobs:cancel`、`jobs:restore`。`attempt` 防旧轮次事件覆盖，`cancelRequested` 防取消后重开误变成继续下载。
- 重新解锁只读取本地任务，不自动联网续传。手动恢复先验证账号版本、域名、远端对象和本地已确认前缀。
- 私有云、Session Token、S3 绑定和其他 S3 供应商仍保留原下载路径；本轮没有为这些连接宣称 Range 持久恢复完成。

## 断点为什么不会直接追加错误内容

1. 保存原对象的大小、七牛内容哈希、修改时间和所选下载源地址；签名 URL 和凭据不进入记录。
2. 恢复时发送 `Range: bytes=<offset>-` 和条件读取；必须得到对应的 `206`、精确 `Content-Range`、一致的总大小及 ETag。
3. 返回完整 `200`、`412/416`、错误范围、压缩编码或不同对象身份时拒绝追加，不把响应硬拼到原断点后。
4. 临时文件还需匹配其记录的文件身份、长度及已确认前缀 SHA256。内容变化、链接替换等情况拒绝截断或清理。
5. 仅在前缀和文件归属校验通过后，才截掉进程中断留下的**未确认尾部**，从最后持久 offset 重取。
6. 流式写入按 4 MiB 检查点间隔及暂停/中断边界执行 flush、sync 和记录保存。写盘或检查点保存失败返回最后已确认断点，不宣称未落盘的新进度可恢复。
7. 下载完整后验证全文件七牛内容哈希，并再次核对远端身份；不通过就不交付目标。

## 原文件保护和取消

- 不截断已有目标，不覆盖并发出现的用户文件。已有同名文件时拒绝任务或交付，请明确选择另一目标或自行处理旧文件。
- 临时文件与目标在同一目录，采用 `.yuncang-range-<job UUID>.part`；最终使用原子 create-if-absent 交付。文件系统不支持这一能力时明确失败，不退化为删除旧文件再重命名。
- `.part` 含下载文件的明文内容，跟随用户选择的目标磁盘；请勿手工编辑、移动或替换。**加密的是任务/断点记录，不是最终文件或 partial 内容。**
- 取消只清理本任务已验证的 partial，不删除目标文件，不向云端发送删除请求。
- 取消与本地交付竞争时，若已完整交付，就保留目标并显示真实完成状态；若取消路径看到目标随后消失，不会重新创建它。
- `Committing` 断点重开后只做本地核对，不再次下载，也不重新解析云端空间。若本地目标已经正确交付，则完成记录；若目标或 partial 不符合预期，保留用户文件并报告中断。

## 本地记录与生命周期

- 下载记录独立存入 `%USERPROFILE%\.config\object0\native-download-jobs`，使用已有密码库内的稳定传输主密钥、AES-GCM 和下载专用 AAD，不与上传记录互相替换。
- 每个记录最多 16 MiB，每个下载记录目录最多 200 个任务；清除已结束任务可释放记录槽。记录损坏、密钥不匹配或路径异常不会被当成“没有任务”。
- 锁库/退出保留断点并清空内存视图，不清理 partial；恢复时需要原密码库和匹配的账号版本。
- 账号版本变化仍会阻止恢复及取消，避免将旧任务解释成新连接；本轮没有增加跨账号重新绑定/强制忘记任务。
- 历史条数限制不会再把排队、暂停、中断任务从可控制列表中挤掉。
- 清理 native 行必须先确认对应加密记录实际删除；避免“刚完成的任务被清掉 UI、磁盘记录却留下，重开后复活”。
- 取消或恢复一个已弹出但尚未被 runner 接管的旧轮次，会释放旧调度槽，不阻塞并发数为 1 的队列。
- 重开不改写已完成时间，不覆盖已经记录的具体错误原因。

## 关键本地验证

- 6 MiB 文件：下载部分数据 → 暂停 → 重新打开 AES 记录 → `attempt` 递增 → 正确 Range offset 续传 → 全文件一致并完成。
- 缺失/错误 Range、远端变更、短流、partial 篡改和检查点写盘失败。
- 已有/并发目标保留；Committing 无云客户端即可本地对账。
- 持久取消重开仅清本地 partial；确定性重现并修复取消路径重新创建目标的竞争。
- 重启分类不入队、锁库保留 offset/取消意图、旧轮次与清理活动 runner 保护。
- 上传和下载共用调度器的历史保留、清理跨阶段竞态、旧并发槽释放回归。
