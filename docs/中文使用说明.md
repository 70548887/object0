# object0 中文版使用说明

此分支基于 object0 v1.5.0，将主要界面和常见提示改为简体中文。存储桶、对象路径、访问密钥和 S3 协议参数沿用原格式。

## 首次使用

1. 设置至少 8 个字符的密码，创建本地密码库。
2. 保存程序显示的恢复密钥。忘记密码时，需要使用它恢复密码库。
3. 根据需要决定是否勾选“在系统钥匙串中记住密码”。

中文版与原版使用相同的本地资料目录和密码库格式。Windows 用户资料默认保存在 `%USERPROFILE%\.config\object0`。切换版本前，请先关闭正在运行的另一版本。

## 添加存储账号

1. 点击侧栏“添加存储账号”，填写方便识别的账号名称。
2. 选择对应服务商，填写接口地址、区域和访问凭据。
3. 对 Cloudflare R2，接口地址为 `https://<账号ID>.r2.cloudflarestorage.com`，区域通常填写 `auto`。
4. 若凭据只能访问某个存储桶，可在“默认存储桶”中填写其名称。
5. 点击“测试连接”，确认信息无误后保存。

具体的桶列表和读写权限取决于存储服务商为该凭据授予的权限。

## 查看和复制已保存的账号信息

在左侧存储账号上点击鼠标右键，选择“查看账号信息”，可以查看账号名称、接口地址、区域、默认存储桶和访问密钥 ID。访问密钥默认隐藏，可点击“显示”查看或“复制”直接复制。

右键菜单的“编辑”下方提供“测试连接”和“复制信息（含密钥）”。测试连接使用已保存的凭据；复制信息会把连接配置和密钥一起放入剪贴板。“复制指定信息”子菜单支持分别复制普通信息、访问密钥 ID 或访问密钥。

编辑账号时，密钥输入框留空会保留原有凭据；查看功能不会改动它们。

## 管理文件

选择存储账号和存储桶后，可以浏览文件、上传、下载、复制或移动。传输任务会显示在任务面板中。

移动操作成功后会删除来源文件；同步中的“镜像”模式会删除目标位置中多余的文件。执行前请查看界面提示和同步预览。

## 底部存储用量

选择账号和存储桶后，底部状态栏显示当前桶的对象内容大小和对象数量。统计包含全部子目录，切换目录不会改变统计范围；窗口变窄时会缩短显示，仍可点击信息图标查看完整说明。

- 已有 S3 凭据即可使用：程序分页读取对象列表并汇总，标记为“S3 扫描统计”。扫描可能产生列表请求费用，完整结果在内存中缓存 5 分钟，关闭或锁定密码库后清除。
- R2 官方统计：在“编辑账号 → 用量统计（可选）”中填写有统计读取权限的 Cloudflare API Token。令牌保存在原有加密密码库中，普通账号列表和复制信息不会包含它。留空保留原值，勾选移除后保存才会删除。
- 官方统计暂不可用时会回退扫描，并在用量说明中显示原因。官方统计时间是数据快照时间，可能有延迟。
- 刷新按钮重新获取当前桶用量。加载时可以在说明弹层中取消；切换账号或桶、锁定密码库时会取消旧请求。
- 扫描超过 60 秒或 1000 页时，数值前显示“≥”，表示仅为已扫描部分；读取失败显示失败提示，只有确认空桶时才显示 0。
- 上传、移动、删除或实时同步可能改变某个桶后，仅使对应桶的统计失效并更新。下载和打包下载不会触发用量重扫。

R2 的“账号免费额度 10 GB·月”是标准存储的每月计费优惠，同一 Cloudflare 账号下的桶共享。它不是容量上限；当前桶的大小也不代表本月账号账单用量。状态栏按十进制显示 GB（1 GB = 1,000,000,000 字节）。对象内容大小不包含元数据和未完成分段上传；官方返回的元数据大小可在说明中单独查看。

## 版本和更新

本分支为简体中文界面，不提供语言切换。上游自动更新默认停用，避免覆盖定制功能。请从 [本仓库发布页](https://github.com/70548887/object0/releases) 下载中文安装包或便携 ZIP；完整解压便携包后，双击 `object0.exe` 即可使用。具体运行环境和配置保存方式见 [Windows 分发说明](PORTABLE_ZH.md)。
