## 三、后续修复顺序与验收门槛

1. **先闭合账号与基础操作**：受限桶身份/Session Token、私有多区域解析、分项连接验证；批量逐项结果；单文件真实公有闭环。先设计能力矩阵，再按实际支持启用按钮。
2. **再闭合可靠传输**：稳定 key → 加密 task manifest → 原生 checkpoint → paused/interrupted/retry RPC/UI → 锁库/退出/恢复 → Range 下载。每一环都保留“完成不确定”状态；不盲重传或 Abort。
3. **再开放跨云与同步**：源/目标绑定、空间/流量确认、元数据与内容校验、覆盖前置条件、复制成功后条件删除、预览凭证与任务依赖。先 copy，再 move，最后 mirror。
4. **完成专有业务**：目录分享真实会话与范围校验、域名选择、预览/编辑冲突、类型/解冻批量状态、外链导出。
5. **统计和发布验收**：官方分类统计/延迟/权限测试；公有专用空间+前缀验收；私有标待实机；安装包/ZIP/SHA/中英发布说明一致，预览版本不自动设为稳定最新版。

开通任何真实写入前须在本地配置有效凭据并明确测试空间和可清理前缀。归档转换、解冻、加速及其他可能收费操作另行确认。本审计没有授权或执行这些操作。
