本次为 `70548887/object0` 定制分支的 Windows x64 正式分发，基于上游 object0 v1.5.0，保留原项目 MIT 版权声明。

| 文件 | 用途 |
| --- | --- |
| `object0_1.6.0_windows_x64_setup.exe` | 简体中文安装向导，当前用户安装，带开始菜单与卸载入口 |

## 更新内容

- 简体中文界面；账号详情、指定信息复制与右键测试连接。
- 底部显示当前桶对象大小与对象数量，支持有界 S3 扫描及可选 R2 官方统计。
- 用量读取失败给出网络、权限或签名等具体诊断；不将失败伪装为零用量。
- 修复部分重命名失败后用量未失效，以及多账号切换时旧请求覆盖新列表的问题。
- 优化分享弹窗：浅蓝选中态、勾选、单位下拉、深浅主题、窄窗口和有效期校验。
- 区分链接生成失败与剪贴板复制失败，隔离已关闭弹窗的迟到请求。
- 默认停止上游自动更新，避免安装英文上游版本覆盖定制功能。

## 使用与安全说明

- 适用 Windows 10 / 11 x64；不支持 ARM64、32 位系统或直接从 UNC 网络路径运行固定运行时。
- Windows 10 首次运行时，仅为随包 `WebView2Runtime` 文件夹准备 Microsoft 要求的应用容器读取/执行权限；不关闭浏览器沙箱，不修改系统全局设置。
- 便携是指程序免安装，不是账号数据随盘移动。账号密码库仍位于当前用户的 `%USERPROFILE%\.config\object0`；发布包不含开发者账号、凭据、历史数据或密码库。
- 安装版与便携版共享本地配置，请不要同时运行。更新前等待传输完成并退出旧版本。
- 应用与安装包未使用商业代码签名证书，Windows 可能显示未知发布者。请核对本仓库来源及 SHA256，不要关闭系统安全保护。
- 固定运行时不会自行升级；之后应通过本仓库更新整包，以获得新版运行时安全修复。
