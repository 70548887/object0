## 已接入本轮应用链路

### 1. 批量删除逐项反馈

- 七牛原生与 S3 删除 RPC 统一返回每个 key 的成功/失败/未确认原因，不再把 HTTP 成功当作全批成功。
- 重复输入按第一次出现去重；每批最多 1000 项；后续批失败保留之前已确认的结果。
- 服务端缺项、重复结果、额外 key、成功/失败冲突不能被解释为成功。服务端原始错误和凭据不回传。
- 延迟删除与右键删除均消费结果。部分失败展示成功/失败数量、逐项明细，可手动复制失败列表；不自动重试破坏性操作。
- 账号/空间/凭据版本快照与撤销保护保留；后台任务的单一终态仍使用失败聚合，不假称任务逐项重试已经实现。

### 2. 受限账号与 Session Token 的显式 S3 空间通道

在“添加/编辑七牛账号 → 限定空间 / S3 绑定”填写原生名称、**明确的 S3 空间 ID**、S3 区域和该空间接口地址。名称不能替代 S3 ID。

- 非空绑定启用限定空间模式，只显示这些空间，不先调用账号级原生列桶，也不在 403 后自动切换协议。
- 每次解析通过带当前凭据的 S3 ListObjectsV2 小范围读取验证。权限不足、凭据过期、缺桶、无效响应和网络失败均不是连接成功。
- 临时凭据和无账号列桶权限的永久凭据可使用此通道；**仍需有该空间根范围的对象列表权限**。仅授权某个目录前缀的分享会话不属于此功能。
- 公有地址限制官方 HTTPS；私有环境采用用户明确配置的地址，手工多区域要求精确匹配。私有云仍待目标部署实机验收。
- 空间名是用户提供的映射，不表示原生名↔S3 ID 已经由原生 API 验证。因此此模式不调用原生管理接口、原生上传凭证或原生签名。
- 浏览、详情、下载、已获服务端权限的文件删除/重命名和单文件 S3 外链接入现有 bridge；不推断写权限，不开放上传、原生空间管理或目录分享。

### 3. 编辑连接时原生复用已保存凭据测试草稿

- 同一服务商编辑地址/区域/绑定时，AK/SK 留空可在 Rust 内复用已保存凭据测试**当前草稿**，不需要取回密钥，不保存草稿。
- 必须携带匹配的账号版本；锁库、账号变化、缺少版本或单独替换一项密钥时拒绝。
- 更换服务商必须明确重新输入 AK/SK，旧 Session Token 不会自动带给新服务；测试和保存路径保持一致。
- Session Token 留空保留、明确清除、明确替换三种语义分离；同时清除与替换会拒绝。

### 4. 原生域名选择、下载和单文件分享

- 原生七牛分享弹窗读取当前桶域名，选择实际参与后端下载/签名，而不只是保存一个未接线的 UI 值。
- 只允许账号明确配置域名或当前桶已确认的原生 HTTPS 源站；未知域名不签名。没有默认配置时，发现的域名不会自动替用户选中。
- 当前无法确认 Kodo 原生签名兼容的 CDN、测试域名和 S3 域名明确不可选；这部分仍不是完整 CDN 适配。不会创建/绑定域名或绕过服务端访问限制。
- 查询失败时可保留用户明确配置的域名，但明确说明桶关联/策略未验证，不伪造可访问性保证。
- 原生外链不再套用 S3 七天限制。云仓暂设 **30 天应用安全上限**（不是七牛官方上限）；S3 仍为七天。非法/超限输入报错而非静默截断，默认仍为一小时。
- S3 绑定模式的单文件外链经对象读取验证后使用 S3 签名；临时凭据或域名策略可使链接早于界面截止时间失效。
- 选择变化、账号版本变化或关闭窗口会丢弃旧选项/旧链接的迟到结果。下载任务绑定入队时账号版本，不能换凭据后继续解释成同一任务。
