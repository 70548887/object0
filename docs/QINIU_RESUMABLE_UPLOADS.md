# 七牛原生大文件：持久任务与恢复

日期：2026-10-31。分支：`feature/qiniu-kodo`。这是源码中的本地模拟验证版本，尚未进行真实七牛公有云或桌面进程实机验收，也不是新的安装包。

后续已接通公有原生下载的持久 Range 路径；本页保留上传那一轮的边界，下载最新状态见 [Range 下载说明](QINIU_RANGE_DOWNLOADS.md)。

## 本轮已接通

- 公有云原生永久凭据账号上传 **超过 5 MiB** 的文件时，进入分片持久队列；单文件选择、文件夹选择、已有上传 RPC 共用这一入口。
- 入队前读取完整源文件指纹；处理前再次核对。该准备阶段可能耗时，尚未入队时不能通过任务行暂停，可通过锁库中止准备请求。
- 每个任务使用随机 UUID；来源、空间、对象键、账号版本、上传选项、分片、会话到期时间及完成阶段保存为 AES-GCM 加密记录。不保存 AK/SK、上传令牌或签名下载链接。
- 稳定传输主密钥保存在原有加密密码库中；修改密码/恢复密码不改变传输主密钥。首次启用仍遵循旧库升级及加密备份规则。
- 任务目录仍在 **`%USERPROFILE%\.config\object0\native-upload-jobs`**，没有改到其他磁盘或携带到安装包中。
- 新增 `paused`、`interrupted`、`resumable`、`attempt`、`cancelRequested`；只对支持的原生大文件任务显示暂停、恢复和安全重试。

## 准确的状态语义

1. **暂停**：保留已上传分片和加密检查点，不发终止上传请求。
2. **恢复/安全重试**：重新确认账号版本、源文件完整指纹、服务器会话和分片。只复用经过核对的分片；不会把不确定的响应当作成功。
3. **锁库或退出**：保留已有检查点，取消本机在途请求并清除内存任务视图。下次解锁只载入本地记录，**不会自动发起上传**，需要用户手动恢复。
4. **取消**：取消意图先加密落盘，再请求终止上传会话。即使随后锁库/重启，“继续取消清理”也只继续清理，不会误走续传。
5. **完成提交不确定**：`Completing` 在请求之前落盘。恢复只读取对象详情并核对完整大小/七牛内容哈希，不重发 Complete、不盲目 Abort、不删除对象。这个对账不要求本地源文件仍存在。
6. **取消与完成竞态**：如果完成已经提交并被确认，任务显示“已完成”，不会为了满足取消请求删除已经提交的对象。
7. **会话过期**：不自动创建新会话。用户可以明确取消过期任务并重新选择文件建立新任务。未取得 uploadId 的初始化中断可能留下服务端临时会话，由服务端到期回收；客户端不会猜测 ID 清理。
8. **清除已结束任务**：只清理已经结束且 runner 已释放的本地记录，不清除暂停/中断任务，也不发对象删除请求。

任务记录损坏、密钥不匹配或写盘失败会显示错误/不可读取数量，不会把错误当作“没有任务”或完成成功。重置密码库不会悄悄删除旧加密检查点；恢复旧任务需要原密码库及相应密钥。

## 边界

- 5 MiB 及以下仍使用原生表单上传，不属于这一套持久恢复任务。
- 私有云、Session Token 和显式 S3 绑定上传仍未开放；其他供应商的大文件恢复没有因此自动启用。
- 默认分片 8 MiB，允许的分片大小受 1～64 MiB 内存限制，最多 10,000 片；理论受理上限为 64 MiB × 10,000，**并非已实测如此大的文件**。
- 本地最多保留 200 个持久任务记录；清除已结束任务可释放记录槽位。批量入队遇到后续失败时，前面已入队任务不撤销。
- 来源变化、凭据版本变化、会话失效等情况不会自动重新解释为新任务。安全重试不是“忽略错误重新上传”。
- 没有完成下载 Range 恢复、限速、目录分享、七牛跨云/镜像同步、官方分类统计或 Windows 新版本发布。
- 当前没有自动化真实窗口交互、真实进程强杀再启或真实七牛账号验收。生产 runner、加密 Store、恢复分类和协议使用独立 loopback 服务及临时文件验证。

## 关键回归

- 大于 5 MiB：上传第一片 → 暂停 → 关闭并重新打开加密记录 → 轮次增加 → 服务端分片核对 → 仅上传缺失分片 → 全哈希完成。
- 网络中断保留 `Interrupted`；检查点落盘失败后不继续 PUT/Complete/Abort。
- 本地源删除后取消只终止会话；完成不确定时源删除后仍可只读对账。
- 取消意图跨锁库/记录重开保留；旧 runner 不得把 `cancelRequested=true` 写回 false。
- 清除按钮不能删除尚未释放并发槽的终态记录；重启读取不改写真实完成时间。
- 前端拒绝旧 `attempt` 事件；暂停/中断/取消不会被旧 completion 事件误报为失败或成功。
